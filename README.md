# libmlp

Небольшой многослойный перцептрон на C и терминальное демо: ракетка в «понге», которой управляет сеть, обучаемая прямо во время игры.

## Что реализовано

`mlp.h` / `mlp.c` (только стандартная библиотека C):

- Полносвязная сеть произвольной глубины. `mlp_create(sizes, n, lr)` принимает массив из `n` размеров слоёв вместе с входным (например, `{3, 8, 1}`) и шаг обучения.
- Веса и смещения инициализируются равномерно на отрезке [-1, 1] через `rand()`, сид берётся из текущего времени.
- На всех слоях одна активация: сигмоида. Экспонента считается собственной функцией `my_exp` (ряд Тейлора из 30 членов), поэтому `mlp.c` не использует `math.h`.
- Прямой проход: `mlp_forward`. `mlp_predict` прогоняет вход и копирует выход последнего слоя в массив.
- Обучение: обратное распространение ошибки для квадратичной функции потерь, градиентный спуск с постоянным шагом.
  - `mlp_train(mlp, x, y, epochs)` делает `epochs` шагов SGD на одном примере.
  - `mlp_train_batch(mlp, X, Y, batch_size, epochs)` делает `epochs` шагов по градиенту, усреднённому по батчу. `X` и `Y` — массивы указателей `const double *`. После эпох 0, 100, 200, … функция печатает в stdout среднюю по батчу сумму квадратов ошибок. Демо её не использует.
- `mlp_free` освобождает память.

Чего нет: других активаций и функций потерь, softmax, оптимизаторов сложнее градиентного спуска с постоянным шагом, регуляризации, сохранения и загрузки весов, тестов, проверок результата `malloc`.

## Демо (`main.c`)

Поле 40×20 символов. Мяч отражается от верхней, нижней и левой стенок, справа стоит ракетка. Ею управляет сеть 3–8–1 с шагом обучения 0.5.

- **Вход:** координата y мяча, вертикальная составляющая скорости мяча и координата y ракетки. Координаты делятся на высоту поля. Вектор скорости мяча имеет единичную длину, так что вертикальная составляющая уже лежит в [-1, 1].
- **Выход:** при значении больше 0.6 ракетка сдвигается на клетку вниз, при значении меньше 0.4 на клетку вверх, иначе стоит на месте.
- **Цель:** её задаёт простое правило. Если мяч ниже ракетки больше чем на 1 клетку, цель равна 1. Если выше больше чем на 1 клетку, 0. В остальных случаях 0.5. Сеть онлайн учится повторять это правило, то есть это обучение с учителем, а не обучение с подкреплением.
- **Обучение:** пока мяч летит к ракетке, на каждом кадре выполняется 5 шагов `mlp_train` на текущей ситуации.

Счёт растёт за каждый отбитый мяч. При промахе счёт обнуляется, ракетка возвращается в центр, а мяч вылетает заново из левого верхнего или левого нижнего угла. Застрявший мяч тоже перезапускается. Застрявшим считается мяч, который 50 кадров подряд держится ближе 2 клеток к средней точке своих последних 10 позиций.

Между кадрами пауза 40 мс, отрисовка через ANSI-коды терминала. Нужна POSIX-система, потому что используется `usleep`: Linux, macOS или WSL. Выход по Ctrl+C.

## Сборка и запуск

Нужен компилятор C (gcc или clang).

```bash
cc -O2 -o pong main.c mlp.c -lm
./pong
```

Или через CMake (3.10+):

```bash
cmake -S . -B build
cmake --build build
./build/pong
```

## Использование библиотеки

```c
#include <stdio.h>
#include "mlp.h"

int main(void) {
    size_t sizes[] = {2, 4, 1};              /* вход 2, скрытый слой 4, выход 1 */
    MLP *net = mlp_create(sizes, 3, 0.5);

    double x[2] = {0.0, 1.0};
    double y[1] = {1.0};
    mlp_train(net, x, y, 100);               /* 100 шагов SGD на одном примере */

    double out[1];
    mlp_predict(net, x, out);
    printf("%f\n", out[0]);

    mlp_free(net);
    return 0;
}
```

```bash
cc -O2 -o example example.c mlp.c
./example
```

## Структура

- `mlp.h`, `mlp.c`: перцептрон (структуры `Layer` и `MLP`, прямой проход, обучение).
- `main.c`: терминальное демо с ракеткой.
- `CMakeLists.txt`: сборка демо.
